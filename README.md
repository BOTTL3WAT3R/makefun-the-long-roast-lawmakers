A tiny Python program that writes one satirical sentence — a roast of lawmakers who voted to license every AI model, audit every blockchain and register every website, then recessed for a week because their own act existed only as a .docx none of its authors could turn into a PDF — to /output/entry.txt for make.fun's "The Long Roast" bounty.

## Run it

```sh
python3 main.py
```
